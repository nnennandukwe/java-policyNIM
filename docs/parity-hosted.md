# Hosted authorization, admission and durable evaluation jobs

A hosted MCP server has to decide who can read policies, which work can start and what a caller can recover after disconnecting. These rows track the Java changes and the evidence needed to make those decisions the same way as the pinned Python server.

The Python authority column names modules and tests in [Python `fcc5322a6672b0275dcc6e0c299e631df8e8de19`](https://github.com/nnennandukwe/policyNIM/tree/fcc5322a6672b0275dcc6e0c299e631df8e8de19). Python module paths start at `src/policynim/`, and test filenames start at `tests/`. Java class and package names refer to [Java `d544829804891dda1f4e5d5e57f07146eed51342`](https://github.com/nnennandukwe/java-policyNIM/tree/d544829804891dda1f4e5d5e57f07146eed51342). **Open** means source inspection identified the work and the runtime proof is pending. **Partial** means an existing Java path implements part of the row and the full proof is pending. A row closes with its reviewed Java SHA, both runtime revisions and a linked receipt.

## Evaluation jobs and report resources

A caller can submit one immutable suite, disconnect and retrieve its result after a worker restarts. Every mandatory row below is **open**. The Java baseline has two registered tools, an ingest command and a chunk store. It has no durable job store, evaluation worker or owner-scoped report reader. The proposed seams use Spring lifecycle management, Flyway and PostgreSQL. The Python storage format supplies evidence for behavior and canonical identities. Java can use native transactions, bounded reads and proven worker leases.
